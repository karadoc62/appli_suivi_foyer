# Foyer

Application web personnelle de gestion du foyer.

## Objectifs

Foyer a pour objectif de centraliser progressivement plusieurs besoins du foyer :

- gestion du budget ;
- comptes, dépenses et recettes ;
- échéances et événements ;
- planning familial ;
- suivi des véhicules ;
- autres modules à venir.

## Stack

- Angular / TypeScript
- Java / Spring Boot
- PostgreSQL
- Docker
- GitHub Actions

## Environnements

- `develop` : développement
- `main` : production
